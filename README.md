# MindMate Wellness Companion

A responsive, static wellness companion website built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. Profile, mood, water, and journal data are stored in that browser's local storage.

## Deploy with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and the root folder (`/`). The site has no build step.
